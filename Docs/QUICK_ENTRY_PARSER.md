# 极速记账解析器（0.3.1）

`QuickEntryParser` 是纯 Foundation + `NaturalLanguage` 的确定性解析器，不依赖 SwiftUI / Core Data，也不调用联网模型。

## 1. 两个例子

### 电动车

```text
我买了一台电动车，9号M5200花费22000
```

输出：

- 物品：`电动车`
- 备注：`电动车 9号M5200`
- 金额：`22000`
- 类型：支出
- 分类：交通（若账本存在）
- 不会把 `9`、`5200` 当成金额

### 口红

```text
今天财务报表。呃，发现有一项不对劲，这个物品是口红，但是口红价格是1000元
```

输出：

- 物品：`口红`
- 金额：`1000`
- 类型：支出
- 分类：购物（若账本存在）
- 软提醒：`口红 1000 元，高于常见区间，建议核对小票`
- `发现` 不再被当成收入关键词

软提醒只提示，不阻断保存；保存前仍需用户选择账户/分类（若解析未命中）。

## 2. 金额过滤

解析器会跳过：

- 日期/时间：`9号`、`10月`、`2026-10-21`、`12:30`
- 型号：`M5200`、`iPhone15`、`A4`
- 数量：`2台`、`3杯`、`12期`、`5折`
- 容量：`5200mAh`

真正的多个金额（如 `15元` 和 `20元`）仍会触发“多个金额”并阻止一键保存。

## 3. 物品提取

按优先级：

1. 显式物品：`物品是…`、`东西是…`、`商品是…`
2. 购买动词：`买了…`、`购入…`、`下单…`
3. 价格线索：`口红价格是…`
4. 已知物品词表兜底

提取结果放在 `ParsedEntry.itemName`；备注保留物品与型号。

## 4. 价格软提醒

当前阈值示例：

- 口红 > 800 元
- 奶茶/咖啡 > 100 元
- 手机 > 20,000 元
- 电脑 > 30,000 元
- 电动车 > 50,000 元

阈值是启发式，不代表真实市场价格，也不构成消费判断。
